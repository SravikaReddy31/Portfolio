Invisible Robot

The Invisible Robot is an academic prototype designed to assist military personnel by performing surveillance in potentially dangerous areas before human entry. The robot autonomously navigates the environment, detects obstacles using ultrasonic sensors, and selects a safe path. It also identifies risky conditions and provides on-screen danger alerts to improve safety. The system is built using a Raspberry Pi as the main controller, along with a camera module and a 7-inch display. The camera captures real-time surroundings, which are displayed on the screen to simulate an invisibility effect by blending the robot with its environment. Due to hardware limitations, this effect is partially implemented in the current phase. This project is developed as a Phase 1 prototype focusing on obstacle detection, navigation, and alert display. Future enhancements include adding a vibration-based silent alert system for secure communication and improving the invisibility concept using multi-directional displays. The project demonstrates skills in robotics, embedded systems, and sensor integration.​

Raspberry Pi, Python, Ultrasonic Sensors, Camera Module, Embedded Systems, Robotics
